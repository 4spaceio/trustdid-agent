Built for Agents

🔑

KERI Pre-Rotation

Autonomous key rotation without human intervention. Pre-committed next keys ensure seamless rotation even for long-running agents.

🔗

Delegation Chains

Human → Org → Agent → Sub-Agent. Capability attenuation at every step. Cascading revocation when trust is broken.

🌍

Ledger-Agnostic

One DID method across EVM chains (Ethereum, Polygon), KERI infrastructure (ledger-less), and web-based resolution.

📜

W3C VC v2.0

Full Verifiable Credentials engine with SD-JWT selective disclosure. Issue, verify, and revoke agent capability credentials.

💬

DIDComm v2.1

Secure agent-to-agent messaging with authenticated encryption. Trust-ping, agent-auth, and custom protocol support.

⭐

Trust Scoring

On-chain SBT reputation tokens. Weighted scoring based on delegation depth, endorsements, identity age, and behavior.
